
# 曾国藩生平

| 年份        | 年     | 主要经历                                   |
| --------- | ----- | -------------------------------------- |
| 1811      | 0     | 出生于湖南长沙府湘乡县荷叶塘。                        |
| 1820年代    | 10余岁  | 随父亲、塾师读书，开始参加科举考试。                     |
| 1833      | 22    | 考中秀才。                                  |
| 1834      | 23    | 参加湖南乡试，考中举人。                           |
| 1838      | 27    | 会试、殿试中第，成为进士，随后入选翰林院庶吉士。               |
| 1840      | 29    | 授翰林院检讨，开始长期京官生涯。                       |
| 1840—1852 | 29—41 | 在北京快速升迁，历任翰林院侍讲、侍读、内阁学士以及各部侍郎等，升至二品大员。 |
| 1852      | 41    | 奉命赴江西主持乡试，途中得知母亲去世，返回湖南奔丧，京官生涯基本结束。    |
| 1853      | 42    | 奉命在湖南帮办团练，开始建立湘军。                      |
| 1854      | 43    | 湘军正式出征；靖港战败后曾投水，被部下救起。                 |
| 1855—1857 | 44—46 | 长期在江西等地与太平军作战。                         |
| 1857      | 46    | 父亲去世，回湖南守丧。                            |
| 1858      | 47    | 再次出山统兵。                                |
| 1860      | 49    | 出任两江总督，并以钦差大臣身份督办江南军务。                 |
| 1861      | 50    | 湘军攻占安庆，随后准备进攻天京。                       |
| 1862—1864 | 51—53 | 曾国荃率湘军围攻天京，曾国藩负责整体战略、军饷和后勤。            |
| 1864      | 53    | 湘军攻克天京，太平天国天京政权覆灭；封一等毅勇侯。              |
| 1860年代    | 50余岁  | 推动洋务运动，支持近代军事工业和派遣留学生等事务。              |
| 1865—1866 | 54—55 | 奉命北上督办剿捻军务。                            |
| 1868      | 57    | 调任直隶总督。                                |
| 1870      | 59    | 处理天津教案。                                |
| 1870—1872 | 59—61 | 再任两江总督。                                |
| 1872      | 61    | 在南京去世，享年61周岁（虚岁62），谥号“文正”。             |
